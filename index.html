Download the Team Echo launcher

For the Team Echo PVE Server only. Installs the server's mods, keeps them up to date and starts SCUM.

Server: 63.143.56.147:7002

Press Launch in the launcher, then join the server the same way as before. Starting SCUM from Steam stays plain SCUM. If Windows says "Windows protected your PC", click More info, then Run anyway.

Click an area to see what's in it. Live = in the game for everyone. Testing = built, being tried by testers. In progress = being made. Planned = agreed, not started. Idea = being talked about. The percentage is how far along the area's pieces are (live counts fully, testing most of the way, in progress partly).

Plans change as testing goes. Dates aren't promised.
